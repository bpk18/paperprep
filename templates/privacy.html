Privacy Policy

PaperPrep is designed to minimize data collection. We aim to process files in-memory and avoid storing uploaded content on disk or in databases. When files must be handled server-side for a conversion operation, they are used only to produce the requested output and are removed as soon as processing finishes.

What we collect

  • No user accounts or personally-identifying profiles are required to use the core conversion tools.
  • We use localStorage in your browser only for a small set of preferences (for example, the selected theme).
  • We do not track or profile users across sessions beyond such minimal preferences.

Security & retention

Uploaded files are processed transiently. If any server-side logging exists (errors, processing metrics), it intentionally omits file contents. If you have concerns about a specific file or request removal, contact us via the Contact page.

This policy is a short summary. If you need additional legal assurances, please reach out.
